# 首页设计方案

## 定位
品牌引导页 — 展示品牌定位 → 精简功能亮点 → 引导进入各学科工作台

## 页面结构（3 个区域，极简）

### 1. Hero 区
- Logo + **"几何维度"** 品牌名
- 一句标语（如 *"AI 驱动的 3D 交互式学习平台"*）
- 一个醒目的 **"开始学习"** 按钮 → 跳转 /workspace
- 无输入框、无示例标签、无拍照按钮

### 2. 核心功能区（精简为 4 个）
从当前 6 个精简为 4 个：
| 功能 | 说明 |
|------|------|
| AI 解析 | 智能识别题目，自动生成解题步骤 |
| 3D 动态讲解 | 交互式三维模型，自由旋转缩放 |
| 错题本 | 自动记录错题，针对性巩固 |
| 教师模式 | 板书式分步讲解，适合课堂 |

展示形式：极简卡片（图标 + 标题 + 一行描述），无渐变背景，无复杂装饰

### 3. 学科入口区
4 个学科卡片：
- 数学（立体几何、函数、代数）
- 物理（力学、电磁学、光学）
- 化学（物质结构、化学反应）
- 生物（细胞、遗传、生态）

点击卡片跳转对应学科页面

### 不包含的内容
- ❌ 例题库 / 筛选 / 搜索
- ❌ 定价 / 会员升级
- ❌ 最近学习记录
- ❌ 拍照识别入口
- ❌ 页脚

## 视觉设计
- 主题：跟随系统（亮/暗模式自适应）
- 配色：使用现有 CSS 变量（--accent, --bg-base 等）
- 布局：垂直居中、呼吸间距、干净排版
- 响应式：390px 无横向滚动

## 需要修改的文件
| 文件 | 改动 |
|------|------|
| `src/pages/LandingPage.jsx` | 重写为 3 区域极简布局 |
| `src/pages/LandingPage.css` | 重写样式（移除大量旧样式） |
| `src/components/AppNavigation.jsx` | 保留不变（导航栏独立） |
