# 个人工具选型备忘

## 笔记工具：Notion vs Obsidian

- **记录日期**：2026-09-16
- **建议复盘日期**：2026-10-16

### 当前决定

已下载 Notion，**暂不引入 Obsidian**（不双开、不并行维护两套笔记系统）。

### 理由

- 需求画像：知识笔记 + 任务管理 + 日记，不需要协作，手机同步是刚需 —— Notion 单工具即可覆盖。
- Obsidian 的任务/日记依赖插件自行拼装，手机上还需额外搭同步（iCloud / WebDAV / 官方 Sync），属于新增维护负担。
- 最大风险是笔记体系分裂：一半在 Notion、一半在 Obsidian，两边都不完整，检索与回顾价值下降。

### 回头再考虑 Obsidian 的触发条件（满足任意两条）

1. 开始做长篇写作/技术沉淀，需要双链、知识图谱来串联概念，而不只是"存下来"。
2. 明确要求笔记以纯 `.md` 存本地、可 Git 版本管理，不信任云端。
3. 大量离线使用场景（通勤、断网环境）。

补充视角：本项目仓库本身已是 Markdown 知识库（`docs/`、`.claude/skills/`、`CLAUDE.md`、`AGENTS.md`）。
若真要上 Obsidian，更可能的第一用途是"当仓库文档的本地浏览器 + 图谱视图"，而非个人笔记工具。

### 复盘时要回答的问题

- Notion 这一个月实际用起来了吗？哪些场景真的在用？
- 有没有出现"想在笔记之间找概念关系"的反复需求？
- 迁移成本：Notion 可导出 Markdown，届时迁移成本低，不必现在提前投入。
