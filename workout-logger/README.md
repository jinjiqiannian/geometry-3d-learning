# SETLOG

记动作、组数、次数和重量的小工具。数据存在浏览器本地。

## 怎么用

```bash
cd workout-logger
npm install
npm run dev
```

打开终端里 Vite 给出的地址（一般是 http://localhost:5173）。适合手机浏览器。

## 功能

- **今日**：开练、按部位分类加动作、记重量 × 次数、本场备注
- **分类**：胸 / 背 / 肩 / 腿 / 臀 / 手臂 / 核心 / 其他
- **常用**：自定义常用动作库，训练中 ★ 收藏
- **复制上场**：一键带入上场动作并预填上次重量/次数
- **趋势**：同动作近几次最高重量迷你图
- **快捷**：同上一组、重量 ±2.5、点组编辑、组间休息震动
- **历史**：回看、备注、用这场开练、删除
- **设置**：公斤/磅、休息时长、常用管理、JSON 备份

## 技术

React 19 + Vite 8，无后端，localStorage 持久化。
